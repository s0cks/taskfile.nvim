# taskfile.nvim

Neovim plugin for working w/ [Taskfiles](https://taskfile.dev/)

![Example](./assets/example.gif)

## Installation

<details>
  <summary>Lazy</summary>

  ```lua

    's0cks/taskfile.nvim',
    version = '*',
    dependencies = { },
    opts = {},
  }
  ```

</details>
